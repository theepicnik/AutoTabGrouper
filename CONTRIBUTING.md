# Contributing to AutoTabGrouper

Thanks for helping improve AutoTabGrouper! All changes go through a Pull Request review process before merging into `main`.

## Core Principles
- **100% Local-First:** No external analytics, telemetry, or remote scripts.
- **Minimal Permissions:** Avoid adding new `manifest.json` permissions unless strictly necessary.

## How to Contribute
1. **Fork** this repository and create a new branch from `main` (e.g., `fix/url-matching` or `feat/dark-mode`).
2. Test your changes locally via `chrome://extensions` (**Developer mode** → **Load unpacked**).
3. Open a **Pull Request** against `main` describing what changed and why.
4. Once reviewed and approved, your changes will be merged and included in the next Chrome Web Store release.
